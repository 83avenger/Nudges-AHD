# Archived — Option B: one combined card per day (superseded)

The confirmed model is **4 separate nudges per day** (one per pillar, at four
time slots). This alternative — all four pillars on a **single** card, sent once
each morning — is kept for reference only.

**Use the live model in the repo root instead:** `adaptive-card-pillar.json` +
`data/four-pillars/by-nudge.*` + `four-pillars-flow-guide.md`.

Files here:
- `adaptive-card-four-pillars-combined.json` — one card, four labelled sections.
- `by-day-flat.json` / `.csv` — 21 rows (one per day, pillars as flat columns).
- `by-day.json` — nested per-day view.
