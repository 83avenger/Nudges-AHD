# Archived — Generic 250-Nudge Draft (superseded)

These files were an early, **English-only** draft built from the first generic
"Wellbeing Nudges Automation" document, before the real **AHD Wellbeing365 —
Month of Connection** workbook (bilingual, 21 dated challenges) was provided.

They are kept only for reference. **Use the bilingual pilot package in the repo
root instead** (`data/month-of-connection.*`, `adaptive-card-bilingual.json`,
and the updated guides).

- `nudges.csv` / `nudges.json` — 250 generic English nudges.
- `adaptive-card.json` — English-only card.
- `gen_nudges.py` — generator for the above.
